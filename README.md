# Astride
## Game is currently in works.


This is my game I am making for Hack Club Terra.



## How it is Made



This game is made using Vinculum's C# port of Raylib and Raygui by Raysan5 meant for C.



## About the Game



This is a shooter that requires you to shoot in order to move around, with the goal of saving lost astronauts and fight bosses. But the catch is, you are in a spaceship that can only shoot one bullet at a time to both move and survive; and with only one hit from the astroids or blackhole to game over. Shoot astroids, pick up astronauts, and run from the blackhole behind you to survive!

## How to Run



1. Download the latest Astride_Win64.zip
2. Extract the folder inside the zip
3. Run Astride.Desktop.exe in the folder extracted



## Controls



Just aim with mouse and shoot with left mouse button!
